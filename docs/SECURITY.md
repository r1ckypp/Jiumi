# Reporting a security issue

**English** · [简体中文](zh-CN/SECURITY.zh-CN.md)

If a report concerns private pet data, account credentials, the plugin sandbox or the native bridge, share it privately with a maintainer. On GitHub, use **Security → Report a vulnerability** when the repository offers that option. If no private channel is listed, open an issue asking for a private contact and keep the technical details for that conversation.

Include the affected version or commit, host, expected permission boundary, observed behavior and impact. Use a disposable pet and redact tokens, account details and private artwork. Coordinate publication of sensitive details with the maintainer handling the report.
