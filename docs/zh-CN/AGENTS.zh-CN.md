# 啾咪桌宠框架贡献指南

[English](../../AGENTS.md) · **简体中文**

啾咪是一个轻量、可扩展的桌宠框架。创作者可以自带素材，用自己常用的 Agent 或独立制作器创建角色，在本机离线运行、编辑和导出。维护这条流程时，应确保它无需账号或常驻服务。外部服务属于可选集成。当前已实现的能力见 [README](README.zh-CN.md)。

## 角色制作与渲染

- 从一段描述或一张图片开始制作。编辑时沿用角色身份、素材、设置和插件。用户只想改眼睛颜色时，就只改眼睛。
- 默认使用免调的方糖分件，初始角色是奶油黄小鸡。根据角色和动作推断渲染方式，需要人形关节联动时才加载进阶说明。单个动作可以用用户提供的动画帧覆盖。所有渲染方式响应同一套动作名。[角色渲染设计](../spec/character-rendering.zh-CN.md)
- 交付可编辑的角色包和可运行的宿主模板，包含本机存档、设置和插件加载。用 TypeScript 维护制作器和公共类型，发行包内嵌编译结果。独立制作器和导出的 HTML 应能作为本地文件直接打开。预览和原生窗口共用播放器。在 macOS 上，创建请求默认交付 HTML 预览和可双击启动的应用。[离线桌宠设计](../spec/offline-pet.zh-CN.md)

## 行为扩展

适配器报告事件，插件请求反馈，宿主协调打断，角色决定如何表现。在插件内定义状态的进入、退出和恢复，让新增行为可以复用到不同宿主。保留一个能运行的示例，演示事件订阅、反馈和资源清理。[事件与反馈](../spec/event-feedback.zh-CN.md)

身体动作、会话提醒和用户操作分别管理。例如，拖动可以打断身体动画，待处理的提醒仍然保留。各宿主声明自己支持的操作。本机监听须由用户明确启用。[宿主能力](../spec/host-capabilities.zh-CN.md)

## 宿主生命周期与可移植性

稳定的宠物 ID 随素材、设置、已启用插件和版本一起迁移。运行实例只对应某台设备上的一次启动。窗口位置、显隐、设备授权和会话跳转地址保存在本机。

| 阶段 | 宿主行为 |
| --- | --- |
| 首次启动 | 创建默认配置和本机存档，显示角色并提供管理入口。 |
| 就绪 | 恢复设置及已启用插件。在素材、控件和事件处理均可用后报告就绪。可选插件失败时，桌宠仍可使用。 |
| 运行 | 协调待机、抚摸和移动。反馈结束后，恢复当时适用的状态。 |
| 隐藏与显示 | 保留唤回同一实例的入口，例如菜单栏或系统托盘，提供显隐、位置复位、设置与退出操作。 |
| 休眠与唤醒 | 根据经过的时间和当前任务状态恢复，每个到期提醒只结算一次。 |
| 退出与恢复 | 释放插件资源并保存已确认的编辑，重新打开时恢复同一只角色及其定制。 |

## 验收与维护

基础验收使用单张素材，在断网且关闭可选插件的情况下检查预览、抚摸、HTML 导出和重新打开。桌面宿主还应检查隐藏与唤回。扩展单独验收启停、打断、恢复及故障回退。

英文和简体中文文档成对维护。记录已确认的设计决策，区分已实现的行为和设想。命名、注释和署名遵循项目约定。用户询问建议时先回答，明确要求实施时再修改文件。
