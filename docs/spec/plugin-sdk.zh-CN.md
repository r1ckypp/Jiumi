# 离线插件 SDK v1

[English](plugin-sdk.md) · **简体中文**

可运行的例子是 examples/focus-timer/index.ts。作者使用 AssemblyScript 的 TypeScript 子集，把功能编译成 Wasm。基础宿主无需 npm、编译器或在线模块解析。SDK v1 适合计时、接收助手事件和请求动作等小模块。

发行 JSON 包含 id、version、api、name、events、capabilities、wasm 和 sha256。wasm 为 Base64 字节，sha256 为这些字节的十六进制摘要。摘要用于一致性校验，发布者身份取决于用户选择的分发来源。宿主至多启用八个模块，每个模块在独立 Worker 的 Wasm 实例中执行。宿主验证模块格式、导入和内存上限，超时或错误时终止对应 Worker。

导出函数为 `step(event:i32, now:f64, state:f64):void`。event 索引对应清单的 events 顺序，从 0 起算。now 是 Unix 毫秒。state 为此角色和插件拥有的一个安全整数，默认 0。可用导入为 pet.save(f64) 和 pet.play(i32)，分别需要 state 和 motion 能力。动作编号 1 为专注，2 为招手。宿主在回调成功后应用最后一个状态写入和动作请求。插件可用状态保存截止时间，跨版本升级需保持此整数语义兼容。

生命周期事件包括 host.ready、host.hide、host.resume、host.tick 和 host.stop。首版 tick 在可见时约每秒一次；计时器应比较实际时间。停用时宿主回收 Worker、清理计时器；终止通知只用于收尾，页面被强制关闭时可能无法交付。可恢复进度应在每次有效事件中立即提交。操作系统事件由用户授权的本机适配器转换为 v1 事件。插件没有环境 API、网络或文件系统导入。

在制作器导入插件包即可安装，通过复选框启停，也可移除代码包。停用保留状态。离线角色带有启用 ID、固定版本的模块字节和可迁移状态；已有存档缺少这些字段时正常打开。H5 中可导出当前角色包，macOS 悬浮窗右键提供导出菜单。本机 CLI 可读取桌面宿主保存的进度。

## 声明式交互状态

复制已安装 Skill 的 `examples/pickup.json`（仓库源文件为 `skill/jiumi-pet/runtime/pickup.json`）。在「本地插件」导入，或在 `pet.py create` 后加 `--module examples/pickup.json`。每个播放器默认带拎起模板。同 ID 的显式安装包可替换默认行为；取消勾选会停用，移除替换包则恢复内置行为。

新玩法可自行命名插件与状态，指定优先级（0–100）和入口事件。示例的 `enter` 用 `pet.grab` 进入 `held`，其 `on` 用松手事件进入 `landing`，落地动作播放完成后执行 `after`。省略 `after` 表示持续状态。目标可写本插件的状态名；`$resume` 表示接回被打断的插件；`$base` 表示清空栈并恢复最新助手状态。动作播完可以连续转入后续状态，自动转移不能形成循环。当前状态先处理自己的事件；若未处理，优先级更高的插件可抢占。多个候选优先级相同时按插件 ID 排序。

被打断的状态用 `resumeAt` 指定 `$self`（默认恢复自己）、本插件的其他状态，或 `$discard`（跳过自己）。恢复时从所选动作的开头播放。挂起期间仍处理声明的退出事件；宿主隐藏时清理临时交互。每个状态的 `motion` 可以引用内置动作或新的角色动作帧键；缺失素材回退到待机。此格式可离线运行，无需编译 Wasm。现有事件可直接复用，新增系统信号仍需要事件源。
