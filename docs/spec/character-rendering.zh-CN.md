# 可移植角色渲染

[English](character-rendering.md)

没有特别说明时生成方糖小鸡，指定物种时使用对应方糖预设。需要跑跳、挥剑或多关节协调的人形使用人形预设，骑士另带装备。Skill 根据用户描述推断，进阶说明按需读取。用户提供的完整原画及旧角色包保留原有外观。

可选 rig 字段携带类型、部件图片和姿势轨道。方糖部件各自围绕预设连接点旋转，耳、足、肢体、眼睛单独绘制。人形使用正向运动学：躯干→大腿→小腿，躯干→上臂→前臂→装备，躯干→头→羽饰。关节名如 armRight、forearmRight、shinLeft。分件 PNG 使用 160×160 画布，中心为连接点；替换父关节的外观会保留子关节。姿势提供毫秒时长和各关节的一组局部角度，播放器在动作期间插值。导入校验限制图片体积、关节和轨道数量、时长与角度。

交互插件从 pet.grab 进入 held，收到 pet.release 进入 landing，播完后恢复。角色可针对某个动作提供独立 clips，覆盖对应姿势；其余时刻继续使用分件或骨骼。已有动作池和静态图回退继续生效。打断同时取消分件动画和逐帧计时器。减少动态效果时跳过瞬时播放。已知角色的 HTML 只内嵌对应的绘制代码。存档携带 rig，事件源和插件共用。
