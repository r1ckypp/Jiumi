# 制作 Jiumi 桌面客户端

使用包内 pet.py 和共享播放器制作。编辑已有角色时保留原 UUID。应用默认叫 Jiumi.app，应用和菜单栏均使用方糖小鸡图标。只有用户明确给客户端命名时才覆盖 Jiumi。创建请求用中文就传 --language zh-CN，用英文就传 --language en；用户明确指定界面语言时优先采用指定值。后续启动沿用用户在设备上手动选择的语言。

## 设置与菜单

macOS 默认避开原生全屏空间，退出全屏后恢复先前显隐状态。开启鼠标穿透时仍可从菜单栏图标进入设置。macOS 13 及以上的独立应用可启用登录时启动。显隐快捷键按角色保存，导出角色包可带走当前启用的插件。

菜单栏和右键保留显隐、设置、退出。用户选为可见的互动动作在右键直接显示，在菜单栏归入「互动」。移回当前屏幕和鼠标穿透在「桌宠窗口」，陪打字权限在「输入与权限」，导出在「关于」，语言在「应用与系统」。主题、大小、不透明度、角色名字和待机间隔在「外观」。显隐快捷键与登录启动保留各自设置入口。

沿用原生可搜索侧栏。「插件与互动」逐行显示所有已安装插件，包括已关闭项。每行展示名称、版本、独立开关和信息按钮。双击名称或版本与点击信息按钮打开同一详情，查看详情时保持启停状态。文字与控件垂直居中，右侧保留留白，重开客户端恢复用户的开关选择。

## 互动制作

- 新角色默认启用 runtime/chatter.json 随机气泡。每次随机等待 35–80 秒，显示一句内置台词 5 秒；有其他台词时避免连续重复。隐藏桌宠或出现会话提醒时暂停气泡。编辑已有角色应保留用户关闭插件的选择。社区可分享自定义台词和间隔。今后读屏、调用模型需要宿主另外提供能力及授权。
- 制作陪打字角色时，安装 examples/typing.json，为该角色提供 type-left 和 type-right 动作。HTML 从当前页面接收输入，跨应用监听由用户在对应桌面客户端主动开启。每次敲击立即切换动作，重新计算五秒静默时间，插件只接收节奏。拎起动作优先；超时后恢复当下适用的状态。
- 临时状态用 timeoutMs 退出，按动作结束转场用 after。将实际可用动作列入 motionPools.idle，动作之间回到呼吸，每轮重新抽取间隔，默认 8–20 秒，可在「外观」调整。停笔退出和随机待机分别计时。

用打包后的角色离线验收：切换插件后重开、确认初始语言并手动切换。陪打字角色还要试单敲、连敲、停手五秒、两轮随机待机，以及连敲中途拎起。HTML 和原生版使用同一播放器。

## Windows 桌面宿主

在 Windows 上用 `python pet.py desktop-app UUID 交付目录` 打包已有角色，用 `python pet.py open UUID` 启动本地测试。构建机需要 .NET 9 SDK，客户端随目录携带 .NET，并使用系统安装的 Microsoft Edge WebView2 Runtime。交付时保留 `Jiumi.exe` 所在的完整目录。Windows 宿主复用离线播放器，并按角色 UUID 在 Local AppData 保存窗口位置。

在 Windows 上再次打开同一个角色 UUID 时，会召回已有窗口。不同 UUID 的角色可同时运行。复用角色时，用原 UUID 执行 open 或 desktop-app。

托盘和右键桌宠都能打开同一个可搜索的设置窗口，包含外观、桌宠窗口、输入与权限、快捷键、插件与互动、应用与系统和关于。设备设置按角色 UUID 保存。插件启停即时生效，导出角色包会保留当前启用的插件。互动名称、顺序和显隐保留在本机。

Windows 依据桌宠所在屏幕的前台窗口判断全屏。手动隐藏的桌宠在退出全屏后仍保持隐藏。鼠标穿透时可从托盘打开设置。显隐快捷键由 Windows 注册，打包后的应用可为当前用户启用登录启动。跨应用陪打字需要用户主动开启，并已启用相应插件，只向播放器发送敲击节奏。

验收时检查断网启动、点击、长按拖动、两处菜单和设置搜索。调整角色大小、语言和待机间隔，启停插件后重开，调整并恢复互动菜单，并导出当前角色。另在 Windows 测试账户上检查鼠标穿透召回、快捷键冲突、全屏切换、位置恢复和登录启动。
